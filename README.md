# Zenkka CMS

Лёгкая PHP-система управления контентом для генерации наборов данных с помощью ИИ (OpenRouter / Google Gemini).

## Требования

- PHP 8.1+
- Расширение `curl`
- Поддержка `.htaccess` (mod_rewrite не требуется)
- Виртуальный хостинг или VPS

## Установка

1. **Загрузите** все файлы в корень сайта через FTP/SFTP.
2. Откройте в браузере `https://ваш-сайт/install.php`.
3. Заполните форму:
   - Название приложения
   - Логин и пароль администратора
   - API-ключ выбранного провайдера (OpenRouter или Gemini)
   - Параметры генерации
4. Нажмите **«Установить»**.
5. ⚠️ **Удалите `install.php`** с сервера перед выходом в продакшн!
6. Перейдите на `/login.php` и войдите.

## Использование

- **Генерация** — заполните тему, выберите язык, формат и количество элементов.
- **История** — просмотр всех предыдущих генераций.
- **Настройки** — смена провайдера, API-ключей и параметров.
- **Скачать** — каждая генерация сохраняется как JSON-файл.

## Безопасность

- Директория `storage/` защищена от прямого доступа через `.htaccess`.
- Пароль хранится в виде bcrypt-хеша.
- Все формы защищены CSRF-токенами.
- Включена защита от брутфорса (блокировка на 10 минут после 5 неудачных попыток).
- Весь пользовательский ввод экранируется через `htmlspecialchars`.
- Идентификаторы файлов валидируются по строгому шаблону (`gen_YYYYMMDD_[a-f0-9]{8}`).
